## Project Description

This project is a warehouse and order management system for hydro equipment products.

Users can:

- Browse the product catalog.
- Add selected products to their shopping cart.
- Place orders with delivery address details.

Orders have several statuses:

- **Active** — the order is placed but not yet shipped.
- **In Delivery** — the order is currently being delivered.
- **Delivered** — the order has been successfully delivered to the user.

Products are stored in the warehouse, organized on shelves and racks. Each individual product can be located by its exact position (rack and shelf).

Additional information:

- Products come in various types.
- The system includes country information.
- Users may specify their country.
- Users can optionally specify the company they work for.
